## Descripción del proyecto

Aplicación web del Grupo 11 para el TP2 de DSWF. Migra el proyecto del TP1 (HTML/CSS/JS vanilla) a React + Vite, incorporando:

- Sidebar compartida y navegación con React Router.
- Perfiles de los 4 integrantes con interacciones personalizadas (gadgets).
- Colección de favoritos (películas y álbumes) con búsqueda y filtros.
- Sección de API pública (MusicBrainz).
- Árbol de renderizado interactivo.
- Bitácora del proceso de trabajo.


## Desarrollo

Instalar las dependencias:

```bash
npm install
```

Para verificar y aplicar el formato del código:

```bash
npm run format:check  # verifica el formato
npm run format        # aplica el formato
```

Para verificar el proyecto antes de subir cambios:

```bash
npm run lint
```

Para levantar el servidor de desarrollo:

```bash
npm run dev
```

Para generar el build de producción:

```bash
npm run build
```
