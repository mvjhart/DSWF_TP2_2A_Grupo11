# DSWF TP1 — Grupo 11

Aplicación web desarrollada por el Grupo 11 para el Trabajo Práctico 1 de Desarrollo de Software Web Frontend (DSWF), utilizando React y Vite.

## Desarrollo

Instalar las dependencias:

```bash
npm install
```

Para verificar y aplicar el formato del código:

```bash
npm run format:check  # verifica el formato
npm run format        # aplica el formato
```

Para verificar el proyecto antes de subir cambios:

```bash
npm run lint
```
